## 2026-09-22 - [JSON Denial of Service via Float Infinity Overflow]
**Vulnerability:** Even when using `parse_constant` to reject explicit JSON literals like `NaN` and `Infinity`, Python's `json.loads` can still deserialize string representations of numbers that exceed the float maximum limit (e.g., `1e999`) as `inf`. This silent conversion to Infinity can cause downstream logic errors, interoperability failures, and potential Denial of Service if the application expects finite numeric bounds.
**Learning:** `parse_constant` is insufficient for comprehensive bounded-JSON enforcement because it does not intercept standard numeric evaluation. Overflows become `inf` natively during float construction.
**Prevention:** To safely deserialize untrusted JSON containing floats, always provide a custom `parse_float` hook to `json.loads`. This hook must parse the float and explicitly validate it using `math.isfinite()`, rejecting overflow values before they enter the application logic.
