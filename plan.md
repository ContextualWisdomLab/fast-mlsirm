1. **Understand the problem**:
   - The task is to make a UX/accessibility improvement.
   - We need to look for something that makes the interface more accessible or pleasant to use.
   - We found that many static HTML files generated by scripts have elements with `tabindex="-1"` (e.g., `<main id="main-content" tabindex="-1">`) or `tabindex="0"` (e.g., `<div class="table-wrap" tabindex="0">`) but they are missing `outline: none;` on standard `:focus` which can be jarring for mouse users.
   - UX/Accessibility Standard says: "Always use `:focus-visible` instead of `:focus` for generic focusable containers... To prevent visually jarring default browser outlines when mouse users click on them, explicitly set `outline: none;` on their standard `:focus` pseudo-class."
   - Specifically, we need to add `.table-wrap:focus:not(:focus-visible) { outline: none; }` in CSS to avoid showing a focus ring on mouse click. This pattern is missing in `scripts/build_benchmark_report.py`, `scripts/build_buyer_packet.py`, `scripts/build_commercial_release.py`, `scripts/build_figma_evidence_sync.py`, `scripts/build_pr_queue_governance.py`, `scripts/build_procurement_due_diligence.py`, and `scripts/build_release_evidence_index.py`.
