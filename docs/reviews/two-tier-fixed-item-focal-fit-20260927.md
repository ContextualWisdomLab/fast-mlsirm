# All-fixed-item orthogonal two-tier focal Gaussian fit

Issue #2209; stacked on PR #2211 source 84590d3efe5089e71353d9ec3f78af651d164ad6. Owner: main coordinator.

The Rust fit_two_tier_grm_focal_orthogonal fixes every item slope/intercept and updates all primary/specific Gaussian means and variances through the shared posterior scorer. Primary and specific factors remain independent. Caller initialization, quadrature counts, update cap and absolute likelihood-change tolerance are explicit. No study settings, multistart heuristic, hidden variance clamp or prior strength are introduced.

Opened source: Cai (2010), Psychometrika 75, 581–612, DOI 10.1007/s11336-010-9178-0, p587 eq4–6 and pp608–609 Appendices A/B. The Gaussian latent-density M-step implies mean average(E[theta|Y]) and variance average(Var[theta|Y]+(E[theta|Y]-newmean)^2), denominator N. This is a derived Gaussian EM update. The implementation uses the stable conditional-variance form, not subtraction of squared population means. Focal fixed-item calibration is the caller application, not an empirical recovery finding in this single-sample source. It is not Kim's discrete-weight fixed-node MWU-MEM. Docstrings distinguish these claims and limits.

The result retains fitted and initial latent distributions, evaluated person moments, full likelihood trace, number of distribution updates, final signed likelihood change, actual convergence/termination reason, quadrature settings and stopping controls. The trace has initialization plus each evaluated update. Every negative finite-grid change stops with converged=false and retains the decreased state as loglik_decreased; a nonnegative change at most tol is tolerance_met; reaching the update cap without satisfying this is max_iter_reached. Moving finite GH nodes do not guarantee exact-integral EM monotonicity. Invalid Gaussian updates fail with iteration/dimension context; entirely unobserved latent dimensions fail instead of returning a fictitious estimate. Nonzero observed loadings are a necessary check, not proof of joint identification.

Three committed tests compile actual extracted Rust functions/types, the actual shared quadrature module (without its separate test module) and original probability helpers in a small rustc harness: 3 passed, 0 failed. The added test independently checks the first distribution update using posterior raw second moments at moderate means, N denominator, returned state/trace/control provenance, cap nonconvergence, a loose synthetic-tolerance convergence branch, and zero/nonfinite controls and missing dimensions. A deterministic coarse 2-point test produces actual likelihood decrease and verifies nonconvergence with retained state. The 2/7-point fixtures test algorithm/contracts, not study settings or scientific validity. Known-population recovery, actual data convergence and sensitivity remain required. No full Cargo/PyO3/wheel build or hosted acceptance is claimed. rustfmt --check and git diff --check pass. Standalone warnings are unused fields/functions from the extracted dependency subset.
