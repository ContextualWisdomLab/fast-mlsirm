# Fixed-bank two-tier focal scoring

Issue #2209; stacked on PR #2210 commit 83f4445512b2d8b26ed8514792135c719a00caae. Owner: main coordinator.

The Rust public score_two_tier_grm_orthogonal consumes fixed item parameters and caller-declared independent Gaussian latent means/SDs for all primary and specific dimensions. It returns reference-metric person means, second moments, posterior SDs and observed-data loglikelihood. This implements scoring under a supplied distribution, not distribution estimation. No Python binding or actual study results are claimed.

It reuses the reduced E-step. The exact substitution theta=mu+sd*z is performed only on temporary working item slopes/intercepts and posterior moments transform back. Anchored inputs/signs remain untouched. No free-item category-count tables are allocated in this path. Shared validation still requires observed category range, model/input shapes and ordered finite item parameters; fixed-bank scoring permits absent categories/all missing whereas the existing fitter retains category coverage. Focal mean/SD length, finiteness and positive SD, arithmetic overflow and transformed threshold representability are checked. Posterior variance is evaluated before restoring the mean and rejects negative/nonfinite values instead of silently clamping. Extremely concentrated/large distributions may therefore fail numerically; this is not a stability guarantee.

Source: Cai (2010), Psychometrika 75, 581–612, DOI 10.1007/s11336-010-9178-0: p587 equations4–6 Gaussian latent distributions and p609 Appendix B posterior first/second moments.
