# Two-tier 기준 집단의 명시적 GPU 적합

## Added

- 직교 주요인(Φ=I) 기준 집단 적합에서 `device="gpu"`를 선택할 수 있습니다. GPU가 없거나 호출자가 지정한 메모리 예산으로 실행할 수 없으면 실패하며, CPU로 조용히 대체하지 않습니다. 집단별 적합·채점에서도 기준 집단에 같은 장치 선택을 전달합니다.
- 적합 결과에 실제 연산 장치와 GPU 어댑터 이름·백엔드를 기록합니다. 운영체제에서 찾은 GPU 이름이나 요청한 장치를 실행 증거로 대신 쓰지 않습니다.

**범위와 정밀도**

기존 모형, 적분 노드, 초기화, 사전분포, Newton 갱신과 수렴 기준은 유지합니다. 기준 적합은 원래 배정밀도 확률 표의 비트를 GPU에 전달하고, 정수 연산으로 배정밀도 log-product 덧셈을 에뮬레이션합니다. 실제 GPU product의 정규화·기대 빈도와 적률 합산·모수 갱신·원래 likelihood 검증은 Rust CPU에서 실행합니다. GPU native f64나 전체 GPU 계산이라고 주장하지 않습니다. 기존 초점 채점·bifactor의 단정밀도 경로는 바꾸지 않습니다. 상관을 추정하는 주요인 적합은 별도 정밀도 검증 전까지 CPU 경로만 지원합니다.

이 변경은 GPU 속도 향상이나 연구 설정의 수치 수용을 보장하지 않습니다. 동일 입력의 수렴·모수·적합도·실행 시간 대조와 적분 노드 민감도 검증이 별도로 필요합니다. 합성자료 검증은 참가자 자료 분석이나 원고 수치 승인에 해당하지 않습니다.
