### Fixed

- Oblimax rotation no longer delegates its second/fourth-moment power route or objective logarithm to Rust `f64::powi` / `f64::ln`, whose precision is not a package-owned reproducibility contract. The Rust criterion now uses explicit binary64 multiplication for integer powers, conditions finite loading ranges with one exact power-of-two multiplier before moment formation, forms the scale-free fourth/second-moment ratio before logarithm evaluation, and applies a fixed 24-term, Kahan-compensated `atanh` logarithm over an IEEE-754 bit-normalized significand. This avoids both cancellation from separately materializing large `ln(sum4)` and `2 ln(sum2)` terms and avoidable raw-moment overflow/underflow for scale-equivalent finite loadings. The analytic gradient is evaluated in the conditioned coordinates, factored through the fourth/second-moment ratio so exact single-support stationary points remain exactly zero instead of acquiring a cancellation-sized binary64 residual, and mapped back with the same exact scale. Package-owned golden bits, repeated-evaluation identity, analytic-gradient finite-difference coverage, exact single-support stationarity, ordinary scale invariance, exact `2^188` scale cancellation, exact `2^300`/`2^-300` moment-range regressions, and finite/nonzero failure checks define the local deterministic-reference boundary. This does not make other rotation criteria bitwise reproducible, and supported-target parity and psychometric recovery remain separate release requirements.
