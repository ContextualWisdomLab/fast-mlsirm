### Fixed

- Oblimax rotation no longer delegates its second/fourth-moment power route or objective logarithm to Rust `f64::powi` / `f64::ln`, whose precision is not a package-owned reproducibility contract. The Rust criterion now uses explicit binary64 multiplication for integer powers, forms the scale-free fourth/second-moment ratio before logarithm evaluation, and applies a fixed 24-term, Kahan-compensated `atanh` logarithm over an IEEE-754 bit-normalized significand. This avoids cancellation from separately materializing large `ln(sum4)` and `2 ln(sum2)` terms under common scaling. Package-owned golden bits, repeated-evaluation identity, analytic-gradient finite-difference coverage, ordinary scale invariance, an exact `2^188` scale-cancellation regression, and finite/nonzero failure checks define the local deterministic-reference boundary. This does not make other rotation criteria bitwise reproducible, and supported-target parity remains a separate hosted-release requirement.
