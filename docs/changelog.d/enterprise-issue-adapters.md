# Governed enterprise issue evidence adapters

## Added

- Added provider-neutral, source-text-free enterprise source, evidence-span,
  counterevidence, atomic-issue, stakeholder-perspective, candidate-intervention,
  and criterion-level scoring-request adapters under
  `fast_mlsirm.scoring.enterprise_issue`.
- Preserved direct fact, supported inference, counterevidence, unresolved
  ambiguity, and stakeholder value judgment as explicit epistemic roles while
  compiling exact evidence references and provenance into the existing shared
  scoring contracts.
- Added deterministic replay, source-span, role-separation, cross-issue,
  sensitive-metadata, provider-neutral execution, public-docstring, and
  statement/branch coverage without adding sentiment, causal, utility,
  calibration, ranking, or high-stakes automation claims.
