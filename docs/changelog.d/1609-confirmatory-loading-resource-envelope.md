# Confirmatory loading-pattern resource envelope

## Fixed

- Bound confirmatory loading-pattern admission and replay to the existing package-owned `MAX_IRT_RESPONSE_CELLS` logical-cell envelope before full finite/binary scans or dense `int64` materialization. Exact NumPy broadcast/strided views and exact list/tuple matrices that exceed the envelope now fail closed while admissible loading structures retain their existing shape, binary, immutability, and confirmatory-model semantics.
- Canonical loading evidence is now materialized as an exact C-contiguous `int64` NumPy view over immutable package-created byte storage. Public callers cannot re-enable `WRITEABLE` and mutate the constructor-created loading pattern in place, and replay requires that concrete immutable backing contract before binary validation. Read-only views over caller-owned mutable arrays continue to fail closed; `OWNDATA=True` is no longer treated as an immutability/provenance guarantee.
- Immutable serialization converts validated entries through bounded chunks instead of retaining a full dense `int64` copy while duplicating it into the final byte storage. The existing 20,000,000-cell boundary remains admissible while transient canonical-conversion allocation is bounded independently of total pattern size.
- Exact list/tuple inputs now normalize cells lazily into those bounded serialization chunks after shape/resource preflight, and exact NumPy rows inside sequences stream validated entries without `.tolist()` duplication. Sequence admission therefore no longer retains a second matrix-sized Python `normalized_rows` structure before immutable serialization begins.
- Mutable exact NumPy evidence is revalidated at the serialization boundary before integer conversion. A caller-owned floating array that changes from an admitted binary value to a non-binary or non-finite value after the initial vectorized scan now fails closed instead of being silently truncated into canonical `int64` evidence; exact NumPy rows nested in sequence inputs likewise replay scalar binary admission while they stream into immutable storage.
- Exact list/tuple evidence replays its logical-cell envelope at immutable serialization and must yield exactly the preflighted matrix cardinality. Post-preflight growth can no longer exceed the package budget or be silently truncated, and a sequence that shrinks before consumption fails with the stable loading-pattern shape diagnostic rather than becoming partial canonical evidence.
- Top-level exact NumPy evidence now keeps the initially admitted two-dimensional shape authoritative through immutable serialization. A caller-owned array that grows, shrinks, or changes shape after validation is rejected before canonical publication; bounded serializer consumption also probes for surplus entries and maps resize-driven iterator shortage to the stable loading-pattern shape diagnostic while preserving source-dtype binary replay before `int64` narrowing.
