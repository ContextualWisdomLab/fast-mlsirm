# TEPP temporal boundary

## Changed

- Clarify the bounded-context split for time-indexed psychometrics: TEPP owns temporal/event composition and semantics, while `fast-mlsirm` retains reusable Rust numerical psychometric kernels over explicitly supplied occasion/time carriers. The existing CT-AR Rasch estimand is preserved; event ontology, temporal validity, changing-membership history, leakage policy, and EA projection remain foreign-owner concerns behind explicit contracts.
- Align `AGENTS.md` and `CLAUDE.md` with the same executable ownership boundary so coding agents do not recreate TEPP event semantics, introduce cross-service SQL or hidden TEPP runtime coupling, pin an unreleased Context Fabric head, or duplicate estimator values, latent scores, DIF/fit diagnostics, or scientific-validity evidence into the EA decision plane. Architecture/package/backend/toolchain/consumer-lifecycle facts remain eligible for EA projection only through an immutable released `context-graph-contracts` contract with provenance.
- Add `docs/context-map.md` as the DDD ownership map for `Model Specification`, `Estimation`, `Scoring`, `Diagnostics`, `Simulation-Recovery`, `Compute Backend`, and `Public Binding`, including explicit upstream/downstream/ACL relationships to TEPP, psychometrics-commons, context-graph-contracts, and enterprise-architecture-core. The map is guarded by architecture fitness tests and does not alter numerical behavior.
- Add `docs/traceability/temporal-research-ownership.md` to make the accepted ADR-0028 owner decision explicit without rewriting the broad research baseline or invalidating its multilevel/longitudinal citations. The record distinguishes proposed/evolving scientific implementations from accepted bounded-context ownership and keeps recovery/fit evidence outside EA authoritative facts.
