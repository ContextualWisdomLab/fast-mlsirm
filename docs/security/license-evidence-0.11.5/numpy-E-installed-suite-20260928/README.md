# NumPy E installed-wheel suite probe

This is local Linux CPython 3.12.11 test evidence for the exact notice-repaired NumPy E wheel, SHA256 `91c7a71387703c23a9bcf953adcc7b0d3ec8f41e6e9a090afaa3a6532c6c8604`. It is not a rights or published-matrix verdict.

The preserved s1 workspace is `/data/orca/workspaces/fmls-numpy-E-fullsuite-20260928`. Its initial offline installation of locked Hypothesis 6.156.6 failed because that version was not cached. A continuation used cached Hypothesis 6.168.0 and pytest 9.1.1. The first full collection stopped because Meson was absent. A run excluding `f2py/tests` passed 322 tests and stopped at another Meson-dependent test. No NumPy assertion was reached in those two runs.

The original NumPy backend input ledger was rechecked with `sha256sum -c`; Meson 1.12.1, Ninja 1.13.2 and Cython 3.3.0 were installed into the test venv only. The full suite then reported **4,496 passed, 8 skipped, 6 xfailed, 1 failed**. The failure was `test_limited_api_cython[limited_api_cython_3_11_npy2_0]`, raising `TypeError: Shared Cython type cython_function_or_method has the wrong size` after compiling several abi3 targets. The [upstream Cython issue #7914](https://github.com/cython/cython/issues/7914) documents this precise Cython 3.3.0 regression in NumPy's limited-API test and reports that 3.2.9 works. This correspondence is an inference from the retained log and upstream issue, not a local proof that the candidate wheel is fault-free.

A second isolated s1 workspace `/data/orca/workspaces/fmls-numpy-E-cython329-suite-20260928` ran the unchanged NumPy wheel with test-only Cython 3.2.9, process `2077586`. Its official PyPI CPython 3.12 Linux wheel, preserved here, has SHA256 `23e80bc885c599e72072e18d0746df82d394b73100c1e153cda7359e6e59fe09`; live PyPI metadata supplied the filename, size, URL and digest in `cython-3.2.9-pypi.json`. The full installed-wheel suite exited zero: **49,968 passed, 1,934 skipped, 31 xfailed, 2 xpassed, 251 warnings in 1,044.33 seconds**. The exact script, install/version logs, terminal test log and exit marker are in `cython329-repeat/`. The original s1 workspaces remain untouched.

This comparison supports the Cython test-tool regression diagnosis. It covers one local Linux CPython 3.12 installed wheel with the test suite's skips and expected failures; it does not establish Windows/macOS numerical behavior, all license rights, or the published twelve-wheel matrix.

The first workspace and all its logs remain in place. Neither test run changes the E/F NumPy build outputs, original Cargo/Python HOLDs, or the release publication stop.
