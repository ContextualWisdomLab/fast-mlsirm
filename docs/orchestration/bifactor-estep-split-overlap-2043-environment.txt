What the timestamps guarantee
-------------------------------
- cpu_shard duration: monotonic wall interval between CPU shard start and end.
- gpu_shard active_duration: monotonic wall interval from GPU submit return through readback completion.
- intervals_overlap=true: the CPU and GPU shard intervals intersect on the monotonic clock.

What the timestamps do not claim
--------------------------------
- gpu_shard active_duration is not the isolated GPU kernel execution window.
- max_abs_loglik_diff / max_abs_count_diff are reported observations, not acceptance thresholds.
- Q=21 is a smoke grid, not the study setting.
- Q=121 is a representative grid observation, not an acceptance decision.
